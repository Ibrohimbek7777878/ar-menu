📋 TEXNIK TOPSHIRIQ (TZ)
Online Store Guliston — Mobil Ilova
Versiya: 1.0 | Sana: May 2026

1. LOYIHA HAQIDA UMUMIY MA'LUMOT
Loyiha nomi: Online Store Guliston
Maqsad: Yangi Yer shahri va Guliston shahrida joylashgan do'konlarning mahsulotlarini uyda o'tirgan holda ko'rish, narxlarni solishtirish va buyurtma qilish imkonini beruvchi mobil ilova.
Platformalar: Android (min. API 21) va iOS (min. iOS 13)
Texnologiya: Flutter (bitta kod bazasidan ikkala platforma)
Backend: Firebase (yoki Node.js + PostgreSQL) — loyiha hajbiga qarab tanlanadi
Asosiy manzil: O'zbekiston, Sirdaryo viloyati, Yangi Yer shahri va Guliston

2. FOYDALANUVCHILAR ROLLARI
2.1 Oddiy foydalanuvchi (Guest/Buyer)

Ilovaga kiradi, ro'yxatdan o'tmaydi (registration yo'q)
Xaritada do'konlarni ko'radi va izlaydi
Do'konni tanlaydi, mahsulotlarini ko'radi
Mahsulotni savatga qo'shadi
Buyurtma beradi — faqat shu vaqtda ism + telefon raqam kiritadi
Buyurtma tarixini (joriy sessiyada) ko'radi

2.2 Admin

Faqat admin ilovada ro'yxatdan o'ta oladi (email + parol)
Oddiy foydalanuvchi ro'yxatdan o'ta olmaydi — bu qat'iy cheklangan
Admin panel orqali barcha ma'lumotlarni boshqaradi
Ko'radi: barcha buyurtmalar, foydalanuvchilar, do'konlar, mahsulotlar, statistika, ob-havo


3. FUNKSIONAL TALABLAR
3.1 Bosh ekran (Home Screen)

Ilovani ochganda: shahar tanlash (Yangi Yer / Guliston)
Qidiruv paneli (mahsulot yoki do'kon nomi bo'yicha)
Kategoriyalar horizontal scroll ko'rinishida (oziq-ovqat, kiyim, maishiy texnika, dorilar, qurilish va h.k.)
"Yaqin atrofdagi do'konlar" bo'limi — xarita ko'rinishi va list ko'rinishi o'rtasida almashtirish

3.2 Xarita moduli

Yandex Maps va Google Maps integratsiyasi (foydalanuvchi qurilmasidagi ilovaga qarab)
Asosiy joy: Yangi Yer shahri (koordinatalar: 40.5966° N, 68.7786° E)
Xaritada do'konlar marker sifatida ko'rsatiladi
Marker bosilganda: do'kon nomi, rasm, ish vaqti, kategoriya
"Yo'l ko'rsat" tugmasi — Yandex Navigator yoki Google Maps navigatsiyaga o'tadi
Filtr: kategoriya bo'yicha markerlarni filtrlash

3.3 Do'kon sahifasi (Shop Page)

Do'kon rasmi, nomi, manzili, ish vaqti
Reyting (admin tomonidan o'rnatiladi)
Kategoriyalar bo'yicha mahsulotlar ro'yxati
Mahsulot qidirish (faqat shu do'kon ichida)
"Do'kon yopiq" belgisi (admin tomonidan o'chiriladi/yoqiladi)

3.4 Mahsulot kartochkasi (Product Card)

Mahsulot rasmi (1 yoki ko'p rasm)
Nomi, qisqacha tavsifi
Narxi (so'm)
Mavjudligi: bor / yo'q
Miqdori (dona, kg, litr va h.k.)
"Savatga qo'sh" tugmasi
Kategoriyasi (non, go'sht, sut, choy, kofe, tuxum va h.k.)

3.5 Savat (Cart)

Tanlangan mahsulotlar ro'yxati
Har bir mahsulot: nomi, soni, narxi
Soni o'zgartirish (+/-)
Olib tashlash
Jami summa
"Buyurtma berish" tugmasi

3.6 Buyurtma berish (Checkout)

Foydalanuvchi kiritadi:

To'liq ismi (majburiy)
Telefon raqami (majburiy, O'zbekiston formati: +998XXXXXXXXX)
Yetkazib berish manzili yoki "O'zim olib ketaman" opsiyasi (ixtiyoriy)
Izoh (ixtiyoriy, masalan: "5ta tuxum, 1 paket choy")


Tasdiqlash ekrani: buyurtma tarkibi, jami summa, kontakt ma'lumotlar
Buyurtma yuborilganda: muvaffaqiyat xabari + buyurtma raqami

3.7 Bildirishnomalar

Admin buyurtma holatini o'zgartirganda push-notification keladi
Holatlar: "Qabul qilindi", "Tayyorlanmoqda", "Yo'lda", "Yetkazildi"


4. ADMIN PANEL FUNKSIYALARI
Admin panel ilovaning alohida bo'limi — faqat admin login qilgandan so'ng ochiladi.
4.1 Dashboard

Bugungi buyurtmalar soni
Jami tushum (bugungi / haftalik / oylik)
Eng ko'p sotilgan mahsulotlar TOP-5
Yangi buyurtmalar sonining grafigi
Ob-havo vidjet (Yangi Yer shahri, OpenWeather API)

4.2 Do'konlarni boshqarish

Do'kon qo'shish / tahrirlash / o'chirish
Maydonlar: nomi, manzili, kategoriya, rasm, ish vaqti, telefon, xarita koordinatalari, aktiv/nofaol
Do'kon xaritada ko'rinishi (koordinatalarni xaritadan ham tanlash mumkin)

4.3 Mahsulotlarni boshqarish

Mahsulot qo'shish / tahrirlash / o'chirish
Maydonlar: nomi, tavsifi, narxi, kategoriyasi, rasmi, mavjudligi, o'lchov birligi
Bir do'konga ko'plab mahsulotlar bog'lash
Ommaviy narx o'zgartirish (filtrlash bilan)

4.4 Kategoriyalarni boshqarish

Kategoriya qo'shish / tahrirlash / o'chirish
Icon yoki rang belgilash
Tartibini o'zgartirish (drag & drop)

4.5 Buyurtmalarni boshqarish

Barcha buyurtmalar ro'yxati (yangi → eski)
Har bir buyurtma: buyurtmachi ismi, telefoni, mahsulotlar, jami summa, sana, holat
Holat o'zgartirish: yangi → qabul qilindi → tayyorlanmoqda → yo'lda → yetkazildi → bekor qilindi
Filtrlash: do'kon, sana, holat bo'yicha
Telefon raqamiga bosib to'g'ridan-to'g'ri qo'ng'iroq qilish

4.6 Foydalanuvchilar (Buyurtmachilar)

Buyurtma bergan shaxslar ro'yxati (ism + telefon)
Qaysi buyurtmalarni berganligini ko'rish
Bloklash (agar spam)

4.7 Lokatsiyalar xaritasi

Buyurtmalar berilgan manzillar xaritada nuqta sifatida ko'rsatiladi (agar manzil kiritilgan bo'lsa)
Issiqlik xaritasi (heatmap) — qaysi mahalla ko'proq buyurtma berayotganini ko'rish

4.8 Ob-havo moduli

OpenWeather API integratsiyasi
Yangi Yer shahri ob-havosi: harorat, nam, shamol, yomg'ir ehtimoli
Maqsad: admin do'konlarga yetkazib berish rejasini ob-havoga qarab moslaydi


5. TEXNIK TALABLAR
5.1 Frontend (Mobil ilova)
Texnologiya : Flutter 3.x (Dart)
Holat boshqaruvi : Riverpod yoki BLoC
Navigatsiya : GoRouter
Xarita : google_maps_flutter + yandex_mapkit
HTTP : Dio
Push : firebase_messaging (FCM)
Rasm : cached_network_image
Storage (local) : shared_preferences + hive
5.2 Backend
Variant A (tez ishga tushish): Firebase
  - Authentication (faqat admin uchun)
  - Firestore (ma'lumotlar bazasi)
  - Storage (rasmlar)
  - Cloud Functions (avtomatik bildirishnomalar)
  - FCM (push notifications)

Variant B (kengaytiriladigan): Node.js + Express
  - PostgreSQL (ma'lumotlar bazasi)
  - Cloudinary (rasmlar)
  - OneSignal (push)
  - JWT auth
  - REST API

8. UX/UI TALABLAR

Dizayn tili: Material Design 3 yoki Cupertino (platforma bo'yicha)
Asosiy rang: yashil (#2E7D32) — tabiiylik va do'konchilik assotsiatsiyasi
Shrift: O'zbekcha belgilarga mos (Roboto yoki Noto Sans)
Til: O'zbekcha (asosiy), imkoniyat bo'lsa rus tili ham
Tarmoq yo'q bo'lganda: offline xabar, cache'dan ko'rsatish
Yuklash holati: skeleton loader (bo'sh joy emas)
Xato holati: aniq xabar + qayta urinish tugmasi
Rasmlar kompressiya qilinib yuklanadi (max 500kb)
Dark mode ixtiyoriy (keyingi versiyada)


9. XAVFSIZLIK TALABLAR

Admin paroli hashed (bcrypt) saqlanadi
JWT token 7 kun amal qiladi, refresh token 30 kun
Oddiy foydalanuvchi admin API endpointlariga kirishi texnik jihatdan imkonsiz bo'lishi kerak
Buyurtma berish limitasi: 1 telefon raqamdan 5 daqiqada max 3 ta buyurtma (spam oldini olish)
Rasm yuklash: faqat jpg/png, max 5MB, server tomonda tekshiriladi


10. ISHLASH TALABLARI (Performance)

Ilova birinchi ochilishi: 3 soniyadan kam
Mahsulotlar ro'yxati yuklash: 1.5 soniyadan kam (yaxshi internet bilan)
Xarita markerlar: 50 ta markergacha tezkor ishlash
Rasmlar: lazy loading, progressiv ko'rsatish
Pagination: 20 ta mahsulot bir sahifada, scroll qilib ko'proq yuklash


11. BOSQICHLI ISHLAB CHIQISH REJASI
Bosqich 1 — MVP (4-6 hafta)
Foydalanuvchi: do'konlar ko'rish, mahsulotlar, savat, buyurtma berish
Admin: login, do'kon/mahsulot CRUD, buyurtmalar boshqaruvi
Xarita: Google Maps (asosiy)
Bosqich 2 — To'liq versiya (2-3 hafta)
Push-bildirishnomalar, Yandex Maps, kategoriyalar boshqaruvi, ob-havo, foydalanuvchilar ro'yxati, lokatsiya xaritasi
Bosqich 3 — Kengaytirish (keyinchalik)
Ko'p tilli qo'llab-quvvatlash, mahsulot reytingi, takroriy buyurtma, SMS tasdiqlash, statistika eksporti
